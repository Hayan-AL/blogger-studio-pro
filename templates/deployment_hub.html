إعدادات مفاتيح Google Cloud OAuth (معرف العميل والمفتاح السري)

لتمكين التفويض الآمن Google Cloud أدخل بيانات الاعتماد الرسمية المستخرجة من مشروعك في Google Cloud Console
لوحة Google Cloud
403 Google لتفادي خطأ (Users فحص) خطوة ضرورية وشاملة: إضافة المستخدم التجريبي
إذا كان مشروعك في وضع التجربة، جوجل ترفض تسجيل الدخول إلا إذا أضفت بريدك كمستخدم تجريبي:
1. فتح شاشة الموافقة:
Google Cloud في مشروعي OAuth افتح شاشة موافقة
فتح شاشة الموافقة في Google Cloud
2. إضافة البريد الإلكتروني (User إضافة):
ثم أدخل بريدك الإلكتروني في قسم Test users
3. نشر التطبيق للحل الدائم (Publish):
لجعل التطبيق يعمل لأي حساب دون قيود اضغط PUBLISH APP بنفس شاشة الموافقة
صفحة شاشة الموافقة
حل خطأ Google رفض الدخول: (no registered origin / 401 invalid_client)
تأكد من إضافة النطاق السحابي https://blogger-studio-pro.pages.dev داخل خانة Authorized JavaScript origins (مصادر JavaScript المعتمدة) في Google Cloud Console وليس فقط في روابط إعادة التوجيه.

مصادر JavaScript المعتمدة (Authorized JavaScript origins)
أضف هذه الأصول في خانة Authorized JavaScript origins في Google Cloud لتفعيل تسجيل الدخول المباشر:
1. سحابي أساسي
https://blogger-studio-pro.pages.dev
2. أصل محلي
http://127.0.0.1:8000
3. أصل محلي
http://localhost:8000
روابط إعادة التوجيه المعتمدة (Authorized redirect URIs)
في إعدادات Client ID، انسخ هذه الروابط في خانة Authorized redirect URIs:
1. سحابي
https://blogger-studio-pro.pages.dev/
2. سحابي
https://blogger-studio-pro.pages.dev/api/auth/google/callback
3. محلي
http://127.0.0.1:8000/api/auth/google/callback
4. محلي
http://localhost:8000/api/auth/google/callback
